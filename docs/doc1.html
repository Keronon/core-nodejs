Welcome to Chess API doc


https://keronon-schemata.vercel.app/api/chess?check

Проверить работу сервиса
> Возвращает параметры запроса, разобранные в json-объект


https://keronon-schemata.vercel.app/api/chess?getFigures

Получить набор фигур и список дейтсвий
> Возвращает json-объект, содержащий:
- поле набора фигур (представленного строкой из буквенных обозначений фигур)
- поле списка действий (представленного объектами Move)


https://keronon-schemata.vercel.app/api/chess?setFigures&set=S

Разместить набор фигур S (представленный строкой из буквенных обозначений фигур) на доске
> Возвращает json-объект undefined


https://keronon-schemata.vercel.app/api/chess?setFigure&to=X&figure=F

Устанавить фигуру F (представленную буквенным обозначением) на позицию X
> Возвращает json-объект undefined


https://keronon-schemata.vercel.app/api/chess?moveFigure&from=X&to=Y

Переместить фигуру с позиции X на позицию Y
> Возвращает json-объект undefined


https://keronon-schemata.vercel.app/api/chess?undoMove

Отменить последнее записанное действие на доске
> Возвращает json-объект undefined


https://keronon-schemata.vercel.app/api/chess?unknown_function

Неизвестная функция
> Возвращает json-объект ошибки с кодом '0-1' и сообщением 'unknown request'
